A successful simulator build does not prove CloudKit authorization. Simulator entitlements are embedded in the executable's `__TEXT,__entitlements` section; an empty `codesign` entitlement dictionary alone does not establish missing permissions. The latest EAS simulator artifact contains the Gains Chat application identifier and approved CloudKit container in that embedded section. Runtime account status and successful schema initialization are the decisive checks.

`scripts/renew-ios-signing.cjs` is a narrowly scoped, one-time recovery helper for the audited local EAS CLI version. Its default mode is read-only. It keeps private credential material in memory and EAS, refuses debug logging, verifies project/bundle/team and the old certificate, and never revokes or deletes credentials. The completed recovery reused the already-created certificate/profile after inspection; do not rerun generation. Its old-credential assertions intentionally stop further use after successful renewal. Apple profile permission wildcards and environment arrays authorize the requested app entitlements; they are not the archive's final signed entitlements.
